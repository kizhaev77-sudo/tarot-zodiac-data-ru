# Таро и зодиак: открытые данные на русском (JSON) и калькулятор числа жизненного пути

Небольшой набор данных и скрипт на Python без зависимостей:

- **значения 22 старших арканов Таро** в JSON: номер, название на русском и английском, стихия, соответствие (планета или знак), ключевые слова для прямого и перевёрнутого положения;
- **12 знаков зодиака**: даты, стихия, качество (кардинальный, фиксированный, мутабельный), управитель;
- **совместимость знаков зодиака по аспектам**: все 78 пар с аспектом (трин, секстиль, квадратура, оппозиция и другие), отношением стихий и качеств;
- **число жизненного пути по дате рождения** (пифагорейская нумерология, мастер-числа 11, 22, 33).

Подходит для чат-ботов, гороскопных приложений, учебных проектов и экспериментов с языковыми моделями. Данные лежат в `data/`, скрипт — в `astro_tools.py`.

> Астрология и Таро не имеют научного подтверждения. Данные описывают традиционные толкования и расчёты по правилам, а не прогноз судьбы.

## Быстрый старт

```bash
git clone https://github.com/kizhaev77-sudo/tarot-zodiac-data-ru.git
cd tarot-zodiac-data-ru
python astro_tools.py tarot shut
python astro_tools.py compat oven lev
python astro_tools.py lifepath 14.03.1990
```

Результат:

```
0 — Шут (The Fool), воздух, Уран
Прямое положение: начало, спонтанность, доверие к пути, лёгкость
Перевёрнутое: безрассудство, страх первого шага, легкомыслие
Подробнее: https://nebogovorit.ru/taro/znachenie/shut/
```

## Значения карт Таро в JSON

Файл `data/tarot_major_arcana.json` содержит 22 карты:

```json
{
  "number": 0,
  "slug": "shut",
  "name_ru": "Шут",
  "name_en": "The Fool",
  "element": "air",
  "element_ru": "воздух",
  "correspondence": "Уран",
  "keywords_upright": ["начало", "спонтанность", "доверие к пути", "лёгкость"],
  "keywords_reversed": ["безрассудство", "страх первого шага", "легкомыслие"],
  "url": "https://nebogovorit.ru/taro/znachenie/shut/"
}
```

Соответствия стихиям и планетам взяты из традиции Золотой Зари с современными планетами (Уран, Нептун, Плутон) там, где это принято. Поле `url` ведёт на подробное толкование карты: образ, любовь, работа, вопрос «да или нет» и сочетания с другими картами.

## Совместимость знаков зодиака: расчёт по аспектам

Файл `data/zodiac_compatibility.json` — 78 уникальных пар знаков (включая пару знака с самим собой). Для каждой считается расстояние между знаками по кругу зодиака и по нему определяется аспект:

| Расстояние | Аспект | Характер |
|---|---|---|
| 0 | соединение | сходство, общие слабые места |
| 1 | полусекстиль | мало общего |
| 2 | секстиль | дружественный |
| 3 | квадратура | напряжённый |
| 4 | трин | гармоничный |
| 5 | квинкункс | непонимание без перенастройки |
| 6 | оппозиция | притяжение и конфликт |

Дополнительно указаны отношение стихий (одна, дружественные, разные) и качеств. Для 22 пар в поле `page_url` есть ссылка на подробный разбор, например [совместимость Овна и Льва](https://nebogovorit.ru/sovmestimost/oven-i-lev/). Для остальных пар `page_url` равен `null`.

## Число жизненного пути по дате рождения

Все цифры даты складываются и сводятся к одной цифре; числа 11, 22 и 33 не сворачиваются:

```python
from astro_tools import life_path, LIFE_PATH

n = life_path("14.03.1990")   # 9
print(LIFE_PATH[n])
```

Более подробное толкование предназначения по дате рождения можно прочитать на странице [«Предназначение по дате рождения»](https://nebogovorit.ru/prednaznachenie-po-date-rozhdeniya.html), а пару по датам рождения сверить на странице [«Совместимость по дате рождения»](https://nebogovorit.ru/sovmestimost-po-date-rozhdeniya.html).
